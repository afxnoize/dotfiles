# Subagent 運用

委譲するのは、出力が大きい探索・独立して並行できる調査・親 context を汚したくない作業に限る。数回のツール呼び出しで済む確認は自分で行う（委譲の起動コストのほうが大きいため）。
同時に起動する subagent は 3 つまでを目安にする。レビュー目的の subagent を自発的に追加しない（高 effort で自己レビューが増え、コストが膨らむため）。
依存のないツール呼び出しは同一メッセージにまとめて並列実行する。

## モデルルーティング
探索・grep・単純確認は Explore に任せる（model は `agents/Explore.md` の frontmatter で固定している）。
それ以外で Agent ツールを直接呼ぶときは task 性質で model を選ぶ（能力とコストの釣り合いを取るため）:
- 計画の曖昧さレビュー → haiku
- 実装・リファクタ・調査 → sonnet
- 設計判断・複雑な分析・レビュー結果の統合 → 委譲せず自分（セッションの上位モデル）で処理

委譲時の指示や実行プランは「最小のモデルが誤解なく解釈できること」を品質基準にする。
解釈の余地が残る指示は、上位モデルがすべき判断を下位モデルに転嫁しているのと同じ。

重い設計判断や多段推論を要するタスクは effort を上げて処理し、軽い確認は低めに保つ。
定義済み subagent（plugin・.claude/agents/）は frontmatter の model に従う。
