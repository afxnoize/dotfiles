# AWS CLI deny/ask patterns for validate-aws.sh
# Format: <regex> | <decision> | <reason>
# decision: deny = block, ask = prompt user
# Lines starting with # are comments, blank lines are ignored.

# ── IAM ──
aws\s+iam\s+delete-                          | deny | Deleting IAM resources is blocked.
aws\s+iam\s+create-(user|role|group)         | ask  | Creating IAM entities. Proceed?
aws\s+iam\s+attach-.*-policy                 | ask  | Attaching IAM policy. Proceed?
aws\s+iam\s+detach-.*-policy                 | ask  | Detaching IAM policy. Proceed?
aws\s+iam\s+put-(user|role|group)-policy     | ask  | Modifying inline policy. Proceed?
aws\s+iam\s+update-role                      | ask  | Updating IAM role. Proceed?
aws\s+iam\s+update-assume-role-policy        | ask  | Updating trust policy. Proceed?
aws\s+iam\s+create-access-key               | deny | Creating access keys is blocked.
aws\s+iam\s+update-login-profile            | deny | Changing login credentials is blocked.

# ── STS ──
aws\s+sts\s+assume-role                      | ask  | Assuming IAM role. Proceed?

# ── S3 ──
aws\s+s3\s+rm\s+.*--recursive                | deny | Recursive S3 deletion is blocked.
aws\s+s3\s+rb\s+                             | deny | S3 bucket removal is blocked.
aws\s+s3api\s+delete-bucket                  | deny | S3 bucket deletion is blocked.
aws\s+s3api\s+put-bucket-policy              | ask  | Modifying bucket policy. Proceed?
aws\s+s3api\s+put-bucket-acl                 | ask  | Modifying bucket ACL. Proceed?
aws\s+s3api\s+put-public-access-block        | ask  | Changing public access settings. Proceed?
aws\s+s3api\s+put-bucket-versioning          | ask  | Changing versioning settings. Proceed?
aws\s+s3api\s+put-bucket-encryption          | ask  | Changing encryption settings. Proceed?

# ── EC2 ──
aws\s+ec2\s+terminate-instances              | deny | Terminating EC2 instances is blocked.
aws\s+ec2\s+delete-(security-group|vpc|subnet) | deny | Deleting network resources is blocked.
aws\s+ec2\s+modify-instance-attribute        | ask  | Modifying instance attribute. Proceed?
aws\s+ec2\s+modify-vpc-attribute             | ask  | Modifying VPC attribute. Proceed?
aws\s+ec2\s+modify-subnet-attribute          | ask  | Modifying subnet attribute. Proceed?
aws\s+ec2\s+authorize-security-group         | ask  | Adding security group rule. Proceed?
aws\s+ec2\s+revoke-security-group            | ask  | Removing security group rule. Proceed?
aws\s+ec2\s+create-security-group            | ask  | Creating security group. Proceed?

# ── RDS ──
aws\s+rds\s+delete-                          | deny | Deleting RDS resources is blocked.
aws\s+rds\s+modify-db-                       | ask  | Modifying RDS configuration. Proceed?

# ── Lambda ──
aws\s+lambda\s+delete-function               | deny | Deleting Lambda function is blocked.
aws\s+lambda\s+update-function-configuration | ask  | Updating Lambda config. Proceed?
aws\s+lambda\s+add-permission                | ask  | Modifying Lambda resource policy. Proceed?
aws\s+lambda\s+put-function-concurrency      | ask  | Changing Lambda concurrency. Proceed?

# ── CloudFormation ──
aws\s+cloudformation\s+delete-stack          | deny | Deleting CFn stack is blocked.
aws\s+cloudformation\s+create-stack          | ask  | Creating CFn stack. Proceed?
aws\s+cloudformation\s+update-stack          | ask  | Updating CFn stack. Proceed?

# ── DynamoDB ──
aws\s+dynamodb\s+delete-table                | deny | Deleting DynamoDB table is blocked.
aws\s+dynamodb\s+update-table                | ask  | Updating DynamoDB table. Proceed?

# ── Secrets Manager / SSM ──
aws\s+secretsmanager\s+delete-secret         | deny | Deleting secret is blocked.
aws\s+secretsmanager\s+(put-secret-value|update-secret) | ask | Modifying secret. Proceed?
aws\s+ssm\s+delete-parameter                 | deny | Deleting SSM parameter is blocked.
aws\s+ssm\s+put-parameter                    | ask  | Writing SSM parameter. Proceed?

# ── Organizations ──
aws\s+organizations\s+(leave|delete)-        | deny | Organizations mutation is blocked.

# ── Route53 ──
aws\s+route53\s+delete-hosted-zone           | deny | Deleting hosted zone is blocked.
aws\s+route53\s+change-resource-record-sets  | ask  | Changing DNS records. Proceed?
